이렇게 동작합니다

  1. 01 / COMMENT

    키워드 댓글

    게시물에 정해 둔 포함 키워드, 예를 들어 “자료”라는 댓글이 달립니다. 제외 키워드가 있으면 답장하지 않습니다.

  2. 02 / MESSAGE

    첫 DM

    댓글을 남긴 사람에게 준비해 둔 첫 DM을 보냅니다.

  3. 03 / CONFIRM

    팔로우 확인

    팔로우 확인을 켜 두면, 받는 사람이 확인 버튼을 누르거나 확인 단어로 답장할 때 팔로우 여부를 확인합니다.

  4. 04 / REPLY

    팔로우에 따른 답장

    팔로우한 사람에게는 준비한 메시지를, 아직 팔로우하지 않은 사람에게는 팔로우 안내를 보내고 다시 확인할 때까지 기다립니다.

할 수 있는 일

댓글 키워드 자동 답장

게시물마다 포함 키워드와 제외 키워드를 정하고, 키워드를 맞추는 방식을 고릅니다.

팔로우에 따른 답장

팔로우한 사람과 아직 팔로우하지 않은 사람에게 서로 다른 메시지를 보냅니다.

연락처와 인박스

댓글을 남긴 사람을 태그와 필터로 나누고, 자동화로 다루기 어려운 대화는 인박스에서 직접 이어받습니다.

처리 상태 확인

메시지가 전송됐는지, 막혔는지, 결과를 알 수 없는지 홈과 보고서에서 확인합니다.

지키는 원칙

  • Instagram이 공식으로 제공하는 기능과 승인받은 권한만 사용합니다.
  • 수신 거부, 24시간 응답 창 같은 발송 조건을 보내기 직전에 다시 확인합니다.
  • 결과를 알 수 없는 메시지는 중복 발송을 막기 위해 자동으로 다시 보내지 않습니다.

시작하는 방법

  1. Instagram 계정 연결 — 관리하는 전문 계정을 연결합니다.
  2. 첫 댓글 규칙 만들기 — 어떤 댓글에 어떤 DM을 보낼지 정합니다.
  3. 발송 켜기 — 계정 발송과 규칙을 켜고, 서비스 전체 발송이 열려 있으면 시작됩니다.
