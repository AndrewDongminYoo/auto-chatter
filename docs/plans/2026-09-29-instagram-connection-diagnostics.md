# Instagram 연결 상태 수동 확인 구현 계획

1. 인증된 계정 소유권과 각 Meta 응답 사례를 API 테스트로 먼저 고정하고 실패를 확인합니다.
1. 저장된 토큰을 서버에서만 복호화해 계정 ID와 계정의 웹훅 구독 필드를 조회합니다.
1. 계정 화면에 수동 확인과 결과를 표시하고 좁은 화면에서 확인합니다.
1. `corepack pnpm check-types`, `corepack pnpm test`, 브라우저 확인과 변경 범위 리뷰를 실행합니다.

Meta의 현재 권한 목록과 다른 사용자에 대한 Advanced Access 승인은 이 수동 진단으로 입증하지 않습니다.
권한·구독 상태의 주기 검사와 발송 차단은 #16의 후속 작업입니다.
