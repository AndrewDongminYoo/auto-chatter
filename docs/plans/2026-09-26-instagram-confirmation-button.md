# Instagram 확인 버튼 구현 계획

1. 선택적 버튼 이름과 대화 스냅샷 컬럼을 추가하고 기존 DB용 마이그레이션을 작성합니다.
   검증: 설정 DB 왕복·기존 값·권한 격리와 마이그레이션 재실행.
2. 버튼 템플릿과 제한 검사를 발송 transport에 연결합니다.
   검증: transport 단위 테스트에서 provider payload·발송 전 거부·기존 텍스트 payload 확인.
3. 서명 검증 뒤 postback을 읽어 해당 수신자·계정·대화만 처리합니다.
   검증: postback 파싱과 DB 상태 전이·중복·외부 계정·과거 버튼 차단.
4. 설정과 대화 미리보기에 버튼을 추가합니다.
   검증: 격리 브라우저에서 기존 규칙 불러오기·켜기/끄기·저장 payload·모바일 렌더링.
5. 전체 타입·단위·DB·workerd·Trunk 검사, 독립 적대적 리뷰, 의미별 커밋과 PR을 진행합니다.
   병합 전 운영자 시각 승인과 현재 커밋의 호스팅 리뷰·CI를 확인합니다.
