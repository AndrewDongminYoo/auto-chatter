# 발송 설정 안내 구현 계획

## 승인된 방향

#353의 기존 상태 함수를 확장하고 바닐라 JavaScript와 현재 디자인을 유지합니다.
새 의존성이나 상태 관리 계층은 추가하지 않습니다.

## 구현과 검증

1. `global-send-state.js`와 기존 단위 테스트에서 설정 조합, 연결 확인 필요 및 조회 실패를 검증합니다.
2. `app.js`, `inbox.js`, `index.html`에 공통 안내와 설정 재확인을 연결합니다.
   상태 갱신은 텍스트만 바꾸고 입력·조회·수동 답장 정책은 유지합니다.
3. 합성 API 회귀 fixture에서 입력 보존과 실패 복구를 확인하고 기존 기능 불변식에 변경한 계약을 기록합니다.
4. `corepack pnpm check-types`, `corepack pnpm lint`, `corepack pnpm test`, `trunk check --all --monitor=false`를 실행하고 실제 렌더링과 키보드 포커스를 확인합니다.
5. 최종 diff를 검토하고 PR의 기술 검증을 마친 후 시각적 승인을 요청합니다.

## 경계와 위험

조회 실패를 확인 필요로 변경하므로 기존 화면 유지 테스트도 새로운 계약으로 갱신합니다.
계정 정보는 마지막 작업 공간 조회 결과이며 실제 Meta 상태나 전달 결과로 해석하지 않습니다.
기존 미추적 파일과 도구 설정은 커밋하지 않습니다.
