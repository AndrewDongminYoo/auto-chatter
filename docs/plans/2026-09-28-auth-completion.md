# 인증 경로 마무리 실행 계획

1. 가입·인증 메일 재전송의 동일 응답과 남용 제한 실패 사례를 테스트에 먼저 추가합니다.
   검증: 새 테스트가 구현 전 실패합니다.
2. Supabase Auth 호출과 Worker의 두 제한 바인딩을 연결합니다.
   검증: 제한 초과 시 HTTP 429를 반환하고 공급자 호출이 없으며, 유형 검사와 단위 테스트가 통과합니다.
3. 만료 링크 안내와 인증 메일 재전송을 로그인 화면에 추가합니다.
   검증: 데스크톱·모바일 브라우저에서 링크 오류, 키보드 이동, 화면 읽기 알림을 확인합니다.
4. 번들 및 관련 통합 테스트를 실행하고 변경분을 검토합니다.
   검증: `corepack pnpm check-types`, `corepack pnpm test`, `corepack pnpm build:cloudflare`가 통과합니다.
5. 배포가 승인되고 병합되면 운영 브라우저에서 실제 메일, 만료 링크, 비밀번호 변경, 로그아웃 뒤 세션 거부를 확인합니다.
   검증: 공급자 응답과 브라우저 결과를 함께 기록합니다.
