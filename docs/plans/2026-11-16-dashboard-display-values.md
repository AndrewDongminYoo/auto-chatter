# API 값 표시 보호 구현

1. `display-values.js`와 기존 테스트에 문자열 및 구분 없는 숫자 표시 회귀를 추가하고 실패를 확인한다.
2. `public/app/`의 화면 문자열 삽입을 조사해 숫자·문자열·날짜 표시 보호를 적용한다.
3. 소스 재발 검사와 mock 메뉴 acceptance fixture를 추가한다.
4. 타입 검사, lint, 단위 테스트, 빌드와 전체 Trunk 검사를 실행하고 변경 전체를 검토한다.
5. 로컬 미리보기 증거를 보존하고 PR의 CI·호스팅 리뷰를 완료한 뒤 시각 승인을 요청한다.
