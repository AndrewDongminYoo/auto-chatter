## 자동 검사 근거

[PR #204 CI](https://github.com/AndrewDongminYoo/auto-chatter/actions/runs/38829735459)의 `test` job은 `90584e9`에서 타입·단위·DB·workerd 검사를 통과했습니다.
[테스트 스크립트](../../package.json)가 아래 파일을 실행 대상으로 포함하는 것도 확인했습니다.

- [예산 단위 검사](../../src/instagram/send-quota.test.ts)는 상수와 SQL 조건을 검사합니다.
- [예산 DB 검사](../../src/instagram/send-quota.db.test.ts)는 699/700 경계, 시간 경과, 다른 연결, 중복 claim 방지, 삭제 호출 이월과 마이그레이션 재적용을 검사합니다.
- [Worker DB 검사](../../src/cloudflare/worker.db.test.ts)는 예산 소진 연결의 깨우기 차단, 수동·팔로우 DM 유지, 100개 초과 연결 순환, Queue 발행 실패와 한 연결의 backlog를 검사합니다.

이는 격리된 테스트 실행의 증거이며 실계정 발송·공급자 승인·운영 DB 적용을 증명하지 않습니다.
초안 미리보기의 합성 API 검사는 화면 상태·요청 직렬화를 확인하며 실제 서버 질의의 정확성은 증명하지 않습니다.
이번 문서 변경에서 제품 테스트를 새로 실행했다는 의미도 아닙니다.

## 남은 조건

[#26 계약](../specs/2026-10-16-segment-draft-preview.md#수용-기준과-제외-범위)과 [#60 계약](../specs/2026-10-12-send-quotas.md#60에-남은-완료-조건)의 제외 범위는 유지합니다.
공급자·실계정 열과 운영 완료 열은 새 실행 증거 없이 변경하지 않았습니다.
나머지 매트릭스 행과 과거 기준 커밋은 이번 대조로 최신 상태가 보증되지 않습니다.
#64의 전체 종단 검증과 출시 판정은 선행 기능·실계정·운영 증거가 갖춰져야 진행할 수 있습니다.

## 문서 검사

변경 문서 네 개의 내부 링크 65개에 대해 파일과 앵커가 존재하는지 확인했습니다.
검사기에 없는 파일과 없는 앵커를 넣으면 각각 실패하는 것을 먼저 확인했습니다.
이 검사는 링크 목적지의 존재만 확인하며 내용의 정확성을 대신하지 않습니다.
형식 검사는 변경 파일을 명시한 `trunk fmt`와 `trunk check --no-fix`로 수행합니다.
