# 수동 답장 현황 로컬 검증

## 범위

[#50](https://github.com/AndrewDongminYoo/auto-chatter/issues/50)의 수동 답장 집계 첫 단계이며, [명세](../specs/2026-10-16-manual-reply-reports.md)를 기준으로 검사합니다.
실제 PostgreSQL 원장과 조회 API를 사용했고 브라우저 로그인·다른 홈 영역의 API만 합성 응답으로 대체했습니다.
운영 DB, 실제 계정 로그인, Meta 전달·읽음, 운영 배포는 확인하지 않았습니다.

## 실패 재현과 기능 검사

API 구현 전 집계 요청의 기대 응답 200 대신 404가 발생했습니다.
권한·시간대·입력 거부 테스트도 없는 라우트의 404로 실패했습니다.
구현 후 집중 DB 테스트 6건이 통과했습니다.
원장의 상태별 합계, 반복 감사 이벤트에 따른 중복 방지, 별도 재시도 행, 다른 연결과 작업 공간 격리, 생성 시각의 마이크로초 경계, 빈 결과, 23·25시간 DST 날짜, 시간대 변경, 관리자 권한과 잘못된 매개변수를 검사했습니다.

화면 구현 전에는 수동 답장 현황 영역이 없다는 검사가 실패했습니다.
구현 후 격리 DB에 합성 요청 135건을 넣고 실제 조회 API를 브라우저에서 읽었습니다.
건수는 대기 20, 발송 중 2, Meta 접수 100, 실패 6, 미확인 3, 미확인 정리 1, 취소 3이었습니다.
화면 합계를 0으로 바꿔 검증기가 실패하는 것을 먼저 확인한 뒤 원래 값으로 복구했습니다.
화면과 CSV의 일곱 상태 및 합계가 같았고, CSV에는 계정 표시 이름이나 메시지 본문이 없었습니다.
입력 변경 후 지연된 응답이 결과를 복원하지 못하고, 시간대 변경 오류가 새로고침 안내로 표시되며, 세션 초기화가 결과를 지우고 상담원에게 영역이 숨겨지는 것도 확인했습니다.
390px 화면에서 문서 폭은 390px로 가로 넘침이 없었습니다.

## 기간 조회 인덱스

호스팅 리뷰에서 짧은 기간 조회도 작업 공간의 과거 요청을 훑을 수 있음을 지적했습니다.
과거 요청 12,000건과 대상 기간 1건을 넣고 실제 집계 SQL을 `EXPLAIN ANALYZE`로 읽는 회귀 검사는 인덱스 추가 전 실패했습니다.
추가 후 계정 필터 유무 모두 새 인덱스의 조건에 작업 공간·시작·종료 경계가 포함되고 실제 읽은 대상 행은 1건임을 확인했습니다.
플래너 설정을 강제로 변경하지 않았으며 이 합성 데이터의 실행 계획이 운영 지연 시간을 증명하지는 않습니다.
인덱스를 지운 격리 DB에서 전체 `deploy/migrate-multi-user.sql` 실행기가 migration 050을 포함해 COMMIT하는 것도 확인했습니다.

## 시간대 표시 호환성

로컬 PostgreSQL은 Factory를 허용하지만 Node Intl은 이를 거부했습니다.
현재 Chromium은 조회한 PostgreSQL 시간대 598개를 모두 지원했으므로 현재 브라우저 장애라고 주장하지 않습니다.
지원하지 않는 Intl 환경을 주입한 회귀 테스트는 수정 전 `Invalid time zone`으로 실패했습니다.
브라우저에서도 Intl 실패를 주입해 빈 날짜와 직접 입력 안내를 확인했습니다.
수정 후에는 날짜를 직접 입력할 수 있고, 조회 결과와 CSV 내보내기를 유지하며 조회 시각을 UTC로 표시합니다.

## 검사 결과

- `corepack pnpm check-types`: 통과했습니다.
- `corepack pnpm test`: 단위 테스트 298건이 통과했습니다.
- `corepack pnpm install --frozen-lockfile`: 의존성 해석과 lockfile이 기존 상태와 일치했습니다.
- `TEST_DATABASE_URL=<격리 로컬 DB> corepack pnpm test:db`: DB 테스트 633건이 통과했습니다.
- `TEST_DATABASE_URL=<격리 로컬 DB> corepack pnpm test:cloudflare`: 번들과 DB/workerd 테스트 78건이 통과했습니다.
- 변경 경로 15개에 대한 `trunk fmt`의 재검사가 통과했습니다.

## 선례와 잔여 범위

Oracle의 `wiki/concepts/source-verified-output.md`를 따라 원장 상태를 전달·읽음·전환으로 확대하지 않았습니다.
`manual reply` 단독 후속 검색은 결과 0건으로 잘리지 않았지만, 최초 reporting 검색의 미반환 결과와 현재 위키 버전은 확인하지 못했습니다.
수동 답장 범위 외 자동화·플로·캠페인·상담 전환·비용 분석은 남아 있습니다.
