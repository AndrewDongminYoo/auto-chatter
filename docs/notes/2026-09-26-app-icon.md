# 앱 아이콘

## 생성과 사용

내장 `image_gen` 도구로 생성한 PNG 원본을 `public/icons/auto-chatter.png`에 보관합니다.
실제 파일 크기는 1254×1254 픽셀이며, 요청한 1024×1024와 다르므로 파일 이름이나 문서에서 1024 이미지로 표기하지 않습니다.
남색 배경에 흰색과 민트색 말풍선을 연결해 댓글과 답장을 표현했습니다.
외부 브랜드 로고나 문자는 사용하지 않도록 요청했습니다.
이는 상표 검색이나 독점성 검증을 뜻하지 않습니다.

공개 안내 페이지의 상단 로고, 브라우저 탭 아이콘, 홈 화면 아이콘에 같은 이미지를 사용합니다.
정적 파일은 [Cloudflare Workers Static Assets](https://developers.cloudflare.com/workers/static-assets/)로 제공하며, 앱 코드나 인증정보를 정적 디렉토리에 넣지 않습니다.
페이지 CSP는 같은 출처의 이미지 로딩만 허용합니다.
Meta 개발자 대시보드의 앱 아이콘 등록은 별도 작업이며 이 배포로 자동 변경되지 않습니다.

앞서 조회한 Oracle의 `wiki/concepts/source-verified-output.md` 선례에 따라 실제 파일 치수와 웹 적용 범위를 확인하고, Meta 등록 성공으로 확대해 보고하지 않습니다.

## 생성 프롬프트

```plaintext
Create one finished app icon for auto-chatter, an independent Instagram comment-to-private-reply automation service. Use-case: logo-design. Output a single square 1024x1024 PNG image, full-bleed opaque solid deep navy background, no exterior rounded-square frame or margins. Center a bold, highly legible original emblem occupying about 65 percent of the canvas: two interlocking rounded speech bubbles that suggest a comment receiving a reply, one ivory white and one fresh mint green, with a small clear negative-space gap where their shapes meet. Friendly precise geometry, flat vector-like surfaces, crisp smooth edges, balanced silhouette, excellent readability at 32 pixels. No text, letters, numbers, gradients, shadows, texture, 3D, mockup, watermark, sparkles, or additional decorative elements. Do not imitate Meta, Instagram, WhatsApp or ManyChat logos. This must be an actual ready-to-use icon image, not an image of an icon placed on a device.
```

## 검증

1. PNG 치수와 형식을 확인합니다. → `sips -g pixelWidth -g pixelHeight -g format public/icons/auto-chatter.png`
2. 공개 페이지와 웹훅 회귀 검사를 실행합니다. → `corepack pnpm test`, `corepack pnpm check-types`
3. 정적 자산을 포함한 배포 구성을 검사합니다. → `corepack pnpm build:cloudflare`
4. 배포된 이미지 바이트를 원본과 비교하고 브라우저에서 실제 이미지 로딩과 모바일 화면을 확인합니다.
