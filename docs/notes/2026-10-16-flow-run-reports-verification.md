# 플로 실행 현황 검증 기록

## 범위와 의미

[#50](https://github.com/AndrewDongminYoo/auto-chatter/issues/50)의 플로 리포트 단계입니다.
[명세](../specs/2026-10-16-flow-run-reports.md)의 생성 기간에 속한 실행 상태와 연결된 첫 답장 상태를 각각 집계합니다.
실행 종료·Meta 접수는 전달·읽음·전환을 뜻하지 않으며 #50 전체를 완료하지 않습니다.

## 로컬 검증

- `corepack pnpm check-types`: TypeScript 타입 검사 통과.
- `corepack pnpm test`: 단위 테스트 300개 통과.
- 격리 PostgreSQL의 `corepack pnpm test:db`: 실제 SQL·제약·권한·기간 경계를 읽는 통합 테스트 638개 통과.
- 같은 격리 DB의 `corepack pnpm test:cloudflare`: Worker 번들과 로컬 workerd·Hyperdrive·Queue 경로 테스트 78개 통과.
- 새 API 테스트는 구현 전 404로 실패했고, 구현 후 상태별 집계·빈 결과·모든 필터 조합·보관된 플로·비활성 연결·활성 관리자 권한·다른 작업 공간 격리·DST·잘못된 입력 검사를 통과했습니다.
- 기간 인덱스를 추가하기 전 실제 집계 쿼리의 실행 계획 검사가 실패했습니다.
  추가 후 기간 밖 과거 실행 12,000개와 기간 안 실행 1개에서 네 필터 조합 모두 날짜 조건으로 인덱스 읽기 범위를 제한하고 대상 1개를 읽었습니다.
  플로를 선택한 경우 기존 플로 이력 인덱스도 허용합니다.
- 새 인덱스를 제거한 격리 DB에서 전체 `deploy/migrate-multi-user.sql` 실행 후 `(workspace_id,created_at,connection_id,flow_id)` 인덱스가 재생성됐습니다.
- `corepack pnpm install --frozen-lockfile`은 manifest와 기존 lockfile의 일치를 확인했습니다.
  의존성 변경은 없습니다.

## 실제 브라우저

격리 Chromium 세션에서 제품의 정적 파일과 실제 `appApi`·PostgreSQL을 사용했습니다.
Supabase 인증 응답은 합성 사용자로 대체했고 실제 Meta 호출은 없었습니다.
테스트 데이터는 실행 9개이며 첫 답장이 없는 실행 3개와 여섯 답장 상태를 포함합니다.

- 실행 합계 9, delivering 3, 나머지 실행 상태 각각 1을 렌더링했습니다.
- 첫 답장 없음 3, 나머지 답장 상태 각각 1을 렌더링했습니다.
- CSV의 15개 집계 행과 화면을 대조했고 UTF-8 BOM 및 계정·플로 이름 제외를 확인했습니다.
- 집계 숫자를 일시적으로 바꿨을 때 대조 검사가 실패하는 것을 확인한 뒤 원래 값에서 통과했습니다.
- 요청을 지연시킨 뒤 날짜를 바꾸면 늦은 응답이 결과·CSV를 복원하지 않았습니다.
- 플로 변경은 이전 결과를 지웠고 새 조회의 합계를 확인했습니다.
- 시간대 충돌 응답은 이전 결과를 지우고 새로고침 안내를 표시했습니다.
- 늦은 플로 목록은 초기화 이후 추가되지 않았습니다.
- 플로 목록 오류가 있어도 전체 플로 조회는 작동했습니다.
- 실제 앱의 세션 초기화는 화면·결과·CSV를 지웠습니다.
- 상담원으로 새로 불러오면 리포트가 숨겨졌고 직접 API 호출은 403이었습니다.
- 데스크톱과 폭 390px 화면을 확인했고 좁은 화면에 가로 넘침이 없었습니다.

브라우저 자동화 도구의 날짜 입력 동작은 값을 비웠으므로, 검증에서는 날짜 입력 요소의 값을 지정하고 실제 input 이벤트와 폼 제출을 발생시켰습니다.
캡처는 저장소 밖의 보존용 검토 디렉터리에 있습니다.

## 검증 한계와 운영

이 결과는 운영 DB 마이그레이션, 실제 Supabase 인증, 배포된 Worker 또는 Meta 발송을 증명하지 않습니다.
운영 규모의 실행 시간·부하도 측정하지 않았습니다.
배포 전 migration 051을 전체 실행기로 적용해야 하며 운영 조회·백업·적용과 배포는 별도 승인이 필요합니다.
화면 캡처에 대한 운영자 시각 승인은 아직 받지 않았습니다.
