## 검증 근거

### 브라우저

실행 도구는 이름이 있는 격리 세션 `auto-chatter-polish`의 `agent-browser`였다.
로컬 주소는 `http://127.0.0.1:4173/app/`이며, 합성 계정·규칙·처리 내역만 사용했다.
외부 계정 설정 변경이나 메시지 전송은 수행하지 않았다.

- 로그인 화면과 설정 화면의 데스크톱·모바일 스크린샷을 실제로 열어 확인했다.
- 320px와 390px 폭에서 문서 가로 너비가 화면 너비를 넘지 않는 것을 확인했다.
- 팔로우 확인을 켜고 후속 문구 없이 저장하면 요청을 보내지 않고 해당 필수 입력으로 포커스가 이동했다.
- 저장 지연 중 버튼이 `저장 중…`으로 바뀌고, 실패 시 초안·수정 상태를 유지하며 재시도로 저장됐다.
- 저장 상태 확인용 검사는 저장 전 `No saved confirmation`으로 실패한 뒤 저장 후 통과했다.
- 저장 중 새 규칙·다른 규칙·계정 연결·로그아웃이 비활성화되고, 요청 완료 후 복구됐다.
  새 규칙을 누르는 시도에도 원래 게시물 ID를 유지했고 PUT은 한 번 발생했다.
- 포함 키워드에 101자를 둔 뒤 모든 댓글로 바꾸고 팔로우 조건을 끄면, 숨긴 키워드는 빈 배열로 저장되며 빈 확인 키워드가 저장을 막지 않았다.
- 계정 목록이 비면 입력과 저장이 비활성화되고 계정 연결 안내가 나타났다.
- 처리 내역 API에 503을 주어도 계정·규칙 편집 화면은 계속 사용할 수 있었다.
- 새 규칙 전환 확인을 취소하면 초안이 유지되고 승인하면 초기화됐다.
  확인의 두 분기는 브라우저 안에서 `confirm` 반환값을 제어해 검증했다.
- `MutationObserver`로 연속 입력 세 번에 저장 상태 DOM 갱신이 한 번만 발생함을 확인했다.
- 모바일 규칙 수정 후 실제 포커스 입력이 화면 안에 들어왔다.
- 본문 바로가기에 포커스를 주고 Enter를 누르면 `#main`이 실제 포커스를 받았다.
- 일반 모션은 `0.12s`, 축소 모션은 `0s`를 확인했다.
  단계적 진입·퇴장이나 크기 변형 애니메이션은 추가하지 않아 느린 재생 검사는 하지 않았다.
- 최종 기본 편집 상태의 `agent-browser --session auto-chatter-polish a11y --json`: axe 4.12.1, 위반 0, 미완료 0, 통과 42.
- 로그아웃 후 로그인 화면의 같은 검사: 위반 0, 미완료 0, 통과 44.
- 팔로우 패널이 열린 상태의 선행 자동 검사: 위반 0, 미완료 1.
  미완료 대상은 장식용 화살표 두 개였으며 색상과 배경을 수동 확인했다.
  이 결과가 화면 읽기 프로그램의 실제 음성 출력을 검증하지는 않는다.

### 코드·번들·리뷰

```bash
node --check public/app/app.js
corepack pnpm check-types
corepack pnpm test
corepack pnpm build:cloudflare
trunk fmt public/app/index.html public/app/styles.css public/app/app.js docs/notes/2026-09-26-dashboard-polish.md
trunk check public/app/index.html public/app/styles.css public/app/app.js docs/notes/2026-09-26-dashboard-polish.md
git diff --check
```

구문·타입 검사와 기존 단위 테스트 74개가 통과했다.
단위 테스트는 서버 정책과 API 등의 기존 동작을 읽으며, 이번 브라우저 조작의 근거는 위 별도 브라우저 검사다.
Cloudflare 번들 dry-run은 성공했고 `SEND_ENABLED=false`를 유지했다.
DB·서버 코드를 바꾸지 않아 DB 통합 테스트는 이번 UI 작업에서 다시 실행하지 않았다.
변경한 네 파일의 Trunk 검사와 `git diff --check`가 통과했다.

상호작용과 접근성을 각각 읽기 전용 로컬 리뷰로 확인했다.
접근성 리뷰에서 제기한 포커스 대비, 반복 공지, 포커스 스크롤, 비활성 입력 표현을 수정했고 재검토는 Clear였다.
최종 직접 점검에서 저장 중 편집 전환 경합과 본문 바로가기의 포커스 대상도 수정했다.

## Oracle 선례

개인 계정의 auto-chatter 범위에서 UI 스타일 관련 직접 선례는 반환되지 않았다.
전역 선례 `wiki/sources/claude--projects---users-dongminyu-development-01-personal--memory--verify-before-publishing.md`는 자동 검사만으로 렌더링과 조작의 성공을 판단하지 말고 실제 화면을 확인하라는 지침이었다.
이에 따라 타입·단위 검사와 별도로 데스크톱·모바일 렌더링 및 오류·재시도 상태를 브라우저에서 확인했다.
반환된 소스 리비전은 `c1681868ac634e4b2414874716bb75a7864113c4`이며 최신성은 검증되지 않았다.
선례를 게시 승인으로 해석하지 않았다.
