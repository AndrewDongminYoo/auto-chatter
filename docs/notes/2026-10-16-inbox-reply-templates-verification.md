# 답장 템플릿 로컬 검증

## 확인 범위

[#24](https://github.com/AndrewDongminYoo/auto-chatter/issues/24)의 [첫 템플릿 단계](../specs/2026-10-16-inbox-reply-templates.md)를 확인했습니다.
예약 시각 지정은 포함하지 않으며 #24를 닫지 않습니다.
운영 DB 적용·배포·Meta 호출·실발송은 수행하지 않았습니다.

## 자동 검사

- 구현 전 새 API 생성 테스트가 `404`로 실패하는 것을 확인했습니다.
- 타입 검사는 TypeScript 소스의 정적 계약을 확인했습니다.
- `corepack pnpm test`: 297개 통과.
  변수 문법·고유 이름 순서·상속 속성 제외·한 번 치환·UTF-16 길이와 기존 단위 계약을 검사합니다.
- 격리된 로컬 PostgreSQL의 `corepack pnpm test:db`: 613개 통과.
  실제 API·트랜잭션으로 역할·작업 공간 격리·50개 생성 한도 경합·버전 충돌·보관·미리보기 비저장·내보내기·전체 삭제·빈 작업 공간 이동 거부를 확인합니다.
- 같은 격리 환경의 `corepack pnpm test:cloudflare`: 75개 통과.
  실제 workerd와 제한된 DB 역할로 템플릿 생성·수정·미리보기·보관·내보내기, RLS와 DELETE 권한 거부를 확인합니다.
- 기존 테스트의 테이블 초기화 목록·공유 데이터 생성기·삭제 함수 마이그레이션 재실행에 새 테이블과 migration 048을 포함했습니다.
  새 테이블이 검증 자료에서 빠진 채 통과하지 않도록 기존 전체 내보내기·삭제 검사를 유지합니다.

## 브라우저 확인

저장소의 실제 HTML·CSS·JavaScript를 격리된 로컬 페이지에서 실행했습니다.
API는 합성 응답이며 테스트 문구와 두 대화만 사용했습니다.
운영 세션이나 계정에는 접근하지 않았습니다.
검사기는 먼저 미리보기 없는 상태에서 예상 문구 검사에 실패했고, 실제 미리보기 뒤 같은 검사를 통과했습니다.

- 미리보기 결과와 기존 초안 뒤에 추가한 문구가 일치합니다.
- HTML 모양의 값은 텍스트로 표시하고 변수 값 안의 `{{name}}`을 다시 치환하지 않습니다.
- 변수 변경과 A → B → A 대화 전환 뒤 늦은 미리보기 응답을 버립니다.
- 합친 길이가 1,000자를 넘으면 기존 초안을 보존합니다.
- 변수 입력에서 Enter는 미리보기만 요청하며 답장 POST가 발생하지 않습니다.
- 답장 접수의 503 응답으로 확인 필요 상태를 만든 뒤 템플릿 적용과 초안 변경이 잠기는 것을 확인했습니다.
- 관리 화면에서 생성·수정·보관과 저장 거부 시 입력 보존을 확인했습니다.
- 로그아웃으로 변수·미리보기·초안을 지웁니다.
- 상담원 세션에서는 관리 영역이 숨겨지고 활성 템플릿 미리보기는 사용할 수 있습니다.
- 1,280px 데스크톱과 390px 모바일에서 관리·작성 화면을 캡처하고 가로 넘침이 없는 것을 확인했습니다.

화면 승인은 운영자에게 요청합니다.
스크린샷과 승인 문서는 Git 제어 상태와 분리된 작업 공간의 검토 디렉터리에 보관합니다.

AGENTS.md는 CLAUDE.md 위임만 유지하므로 바꿀 내용이 없습니다.
개인 계정 `auto-chatter` Oracle의 `reply templates`, `message variables` 검색은 `[no precedent found]`였습니다.
확대 검색은 일부 메타데이터만 반환했고 최신성은 미확인이므로 전체 선례 부재를 뜻하지 않습니다.
