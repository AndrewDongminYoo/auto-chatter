# 댓글 연락처 상세 검증

## 범위와 재현

[#25](https://github.com/AndrewDongminYoo/auto-chatter/issues/25)의 [읽기 전용 상세 범위](../specs/2026-10-04-contact-details.md)를 확인했습니다.
기준은 `origin/main`의 `7b3ea96`이며, 식별자 병합·분리와 CSV 작업은 포함하지 않았습니다.
#17·#27의 미완료 외부 검증과 #25 전체 완료 조건은 그대로 남습니다.

새 `src/app/contact-details.db.test.ts`를 `test:db` 스크립트에 등록했습니다.
구현 전 7개 테스트가 모두 기존 GET의 404 응답 때문에 실패했습니다.
브라우저에서도 상세 펼치기 요소가 없어서 실패한 뒤 화면을 구현했습니다.
DB 검사는 포트 5433의 격리된 로컬 `automations_test`에 합성 데이터만 넣어 실행했습니다.

## DB와 실행 경계

상세 테스트 7개가 다음을 확인합니다.

- 소유자·상담원 조회, 다른 작업 공간·연결과 없는 연락처의 동일한 404, 없는/제거된 멤버십, no-store 응답.
- 잘못된 식별자, 잘못된 인코딩, 허용하지 않은/중복 query, 잘못된 커서, 다른 작업 공간·연결·연락처의 커서 재사용 거절.
- 태그, 활성 필드와 보관 필드 제외, 숫자 0·불리언 false·빈 텍스트·미설정 구분, 직접 중지와 상담 전환 중지의 네 조합.
- 공급자 확인·원본 작성자 일치·현재 인박스 시작 시각을 만족한 저장 대화만 표시. 여러 게시물의 같은 작성자는 허용하고, 다른 작성자의 오래된 근거는 충돌로 제외.
- 오래된/미래 발송, 공급자 ID 없음/공백, 미확정 발송, 다른 원본 작성자, 숫자만 같은 DM, 다른 작업 공간의 근거, 저장 DM이 없는 근거, 인박스 시작 시각 부재 배제.
- 댓글과 DM의 정확한 목적별 현재 동의 구분. 다른 식별자·연결의 마케팅 동의 전이 없음, `all` 철회의 두 목적 투영, 근거 참조 텍스트 제외.
- 대화 상태와 상담 전환 상태, 50개 페이지의 중복 없음, JavaScript 안전 정수를 넘는 답장·메시지·동의 이벤트 ID 보존.
- 댓글/메시지/발송 원문, 토큰, 상담 메모, 다른 멤버의 개인 리마인더가 응답에 없음.
- 실제 트랜잭션이 `repeatable read`·`read only`인지 확인. 조회 전후 전체 제품 테이블 내용 동일, 큐 알림 0회.
- 연락처 조회 도중 다른 DB 세션에서 중지·동의·충돌 근거를 커밋해도 응답의 모든 사실은 처음 스냅샷을 유지하고, 다음 조회는 새 상태를 표시.

타입 검사와 전체 단위 테스트 217개, DB 테스트 497개가 통과했습니다.
Cloudflare 드라이런 번들과 테스트 57개가 통과했습니다.
`trunk check --all --no-fix`는 276개 파일에서 문제 없음을 확인했습니다.

## 실제 브라우저

실제 `public/app` 파일을 로컬 임시 HTTP 서버로 열고 Playwright 1.63.0과 `/usr/bin/chromium`으로 검사했습니다.
API는 합성 요청 대역이며, 서버 API와 PostgreSQL의 검증은 위 DB 테스트에서 별도로 수행했습니다.
실제 `public/_headers`의 CSP를 적용하고 외부 요청을 차단·기록했습니다.
19개 브라우저 항목을 통과했습니다.

- 처음에는 상세 요청이 없고 Enter로 펼칠 때 조회합니다.
- 직접 중지·상담 중지, 0·false·빈 텍스트·미설정이 구분됩니다.
- HTML 형태의 태그가 실행되지 않고 문자로 보입니다.
- 저장 전 태그와 필드 초안은 펼치기·조회 뒤 그대로 남습니다.
- 다음 대화 페이지는 이전 연결 결과를 교체하고, 마지막 페이지에서는 다음 버튼이 사라집니다. 상세 새로고침은 첫 페이지로 돌아갑니다.
- 390px 문서에 가로 넘침이 없고, 상세 summary·버튼 높이는 44px 이상입니다.
- 실패 시 이전 상세가 지워지고 재시도할 수 있으며, 빈 대화 안내는 현재 확인된 저장 대화라는 범위를 표시합니다.
- 접은 뒤와 로그아웃 뒤 도착한 응답은 화면에 반영되지 않습니다.
- 상세 경로는 GET만 호출했습니다. 외부 요청·페이지 오류·CSP 위반은 0건입니다.

데스크톱과 390px PNG를 직접 열어 한국어·긴 식별자·태그·동의 설명의 줄바꿈과 버튼 배치를 검토했습니다.
스크린 리더 낭독과 실기기 터치는 검사하지 않았습니다.
운영 DB, 실제 공급자 인증/발송, 운영 배포는 실행하지 않았습니다.
