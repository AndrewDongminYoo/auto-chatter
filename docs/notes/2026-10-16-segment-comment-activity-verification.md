# 마지막 댓글 저장 기간 검증

## 범위와 결과

[#26](https://github.com/AndrewDongminYoo/auto-chatter/issues/26)의 고정 UTC 마지막 댓글 저장 기간을 [계약](../specs/2026-10-16-segment-comment-activity.md)과 [계획](../plans/2026-10-16-segment-comment-activity.md)에 따라 구현했습니다.
일반 목록·저장된 필터·초안 미리보기는 마지막 저장 댓글의 `[from,before)` 구간을 사용하며 태그/필드 OR로 기간을 우회하지 않습니다.
기간 밖 연락처를 먼저 제외하고 기간 안에서 태그·필드 불일치를 구분합니다.
기존 DB는 전체 마이그레이션 실행기로 046을 적용한 뒤 새 코드를 사용해야 합니다.
운영 마이그레이션·배포·실계정·실발송은 확인하지 않았으며 #26 전체를 완료하지 않습니다.

타입 검사를 제외한 서버 테스트는 기능 구현 전 유효한 기간 요청이 400을 반환하는 실패를 먼저 확인했습니다.
브라우저 검사도 기간 입력 부재로 실패한 뒤 구현을 확인했습니다.
브라우저 fixture를 제거했을 때 `Missing activity fixture`로 실패함을 확인하고 복원한 뒤 통과했습니다.
기존 브라우저 검사의 마지막 단계가 세션을 초기화하므로 활동 검사는 fixture를 새로 초기화한 뒤 실행했습니다.

DB 검사는 시작 직전·시작·종료 직전·종료·이후를 구분하고 이전 댓글이 기간 안에 있어도 최신 댓글이 밖이면 제외되는지 확인합니다.
같은 sender의 다른 계정, 다른 작업 공간, AND/OR의 중복 없는 사유, 0명, 55명의 50+5 페이지, 전체 댓글 수와 첫 댓글 보존, 저장 후 새 댓글 반영을 확인했습니다.
마이그레이션은 기존 행의 null 유지·두 번 적용·저장된 기간 유지·부분/역순/동일/무한 구간의 CHECK 거부를 검사했습니다.
workerd는 제한된 역할로 기간 저장·조회·보관, 최신 시각 변경에 따른 제외와 외부 작업 공간 거부를 실행했습니다.

브라우저 시간대는 `Asia/Seoul`이며 UTC 밀리초가 저장·선택·보관 후 수동 조회에도 보존됨을 확인했습니다.
기간 누락·역순·동일 경계는 요청 전에 거절하고, 서버 오류·누락/잘못된 요약·합계 불일치 후 재시도, 초안 변경 후 늦은 응답 차단을 검사했습니다.
데스크톱 1280×1000과 모바일 390×844에서 입력·정상·0명·오류 화면을 확인했습니다.
모바일 문서 너비는 390px로 수평 넘침이 없었고 키보드 Enter 미리보기와 포커스 표시를 확인했습니다.
화면 자료와 운영자 승인 기록은 체크아웃 밖의 `../pr-loop-reviews/auto-chatter/segment-activity-window-20261016/`에 보존합니다.

## 실제 쿼리의 로컬 비용

로컬 PostgreSQL 17의 UTF-8 격리 DB에 작업 공간 하나, 계정 하나, 연락처 10,000명, 각 3개의 댓글 총 30,000개를 넣었습니다.
1,000명은 lead 태그가 있고 숫자 필드는 짝수 연락처의 값이 0입니다.
첫 두 댓글은 10월 1일, 마지막은 10월 11일 또는 12일이며 4의 배수 2,500명은 종료 경계에 있습니다.
태그·필드·댓글 테이블을 ANALYZE한 뒤 실제 `listContacts`가 실행한 SQL과 바인딩을 포착해 `EXPLAIN (ANALYZE, BUFFERS, FORMAT JSON)`을 한 번씩 실행했습니다.
모든 측정은 캐시된 블록을 읽었고 Shared Read Blocks는 0입니다.

| 요청                      |   일치 수 | 기간 제외 | 실행 ms | Shared Hit Blocks |
| ------------------------- | --------: | --------: | ------: | ----------------: |
| 일반 목록, 기간 없음      | 요약 없음 | 요약 없음 |   0.255 |               432 |
| 전체 미리보기, 기간 없음  |    10,000 |   키 없음 |  10.969 |               847 |
| 일반 목록, 기간 있음      | 요약 없음 | 요약 없음 |  12.941 |               672 |
| 기간 미리보기             |     7,500 |     2,500 |  24.216 |             1,087 |
| 기간+태그/필드 AND        |       500 |     2,500 |  15.020 |             2,458 |
| 기간+태그/필드 OR         |     2,500 |     2,500 |  28.155 |             1,335 |
| 기간에 일치하는 대상 없음 |         0 |    10,000 |  22.438 |               832 |

모든 미리보기의 평가 수는 10,000명이며 일치·기간·태그·필드·둘 다 제외의 합계를 실제 결과로 검증했습니다.
기간 조건은 그룹의 `max(created_at)`에 적용하므로 일반 목록도 샘플 50명만 읽는 비용으로 제한되지 않습니다.
미리보기는 전체 평가 범위와 샘플을 같은 문장에서 읽지만 집계 작업이 두 경로에 들어갑니다.
이 작은 합성 데이터의 단일 측정은 운영 지연 시간, 차가운 캐시, 큰 작업 공간이나 동시 요청의 성능을 보증하지 않습니다.

## 문서와 선례

README의 일반 기능·전체 마이그레이션 안내와 AGENTS의 CLAUDE 위임은 현재 계약과 맞아 유지했습니다.
