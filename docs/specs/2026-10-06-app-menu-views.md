# 대시보드 메뉴별 화면과 시작하기

## 목표

로그인한 뒤의 `/app/`은 연결 계정부터 처리 내역까지 열두 구역을 한 페이지에 이어 붙여 보여 줍니다.
막 가입한 소유자는 무엇부터 해야 하는지 찾기 어렵고, 숙련된 사용자도 원하는 구역까지 오래 스크롤해야 합니다.
이 변경은 구역을 메뉴별 화면으로 나눠 한 번에 한 화면만 보여 주고, 홈에서 첫 자동화까지의 세 단계를 안내합니다.

2026-10-06 운영자가 정한 범위입니다.

- 우선 대상은 막 가입해 Instagram 계정을 아직 연결하지 않은 소유자입니다.
- 화면 구조는 메뉴별 화면과 시작하기 홈입니다.
- Instagram 계정은 설정과 분리한 별도 메뉴에 둡니다.
- 시작하기 안내는 세 단계를 모두 마치면 사라집니다.

## 범위

`public/app/`의 HTML, CSS, `app.js`만 바꿉니다.
서버 API, 인증, DB, 역할 규칙과 각 구역 안의 동작은 바꾸지 않습니다.
역할에 따라 숨기는 구역(운영 상태, 외부 전송, 멤버, 내보내기)은 지금과 같은 조건으로 숨깁니다.

## 메뉴

| 메뉴   | 주소          | 담는 구역                                                          |
| ------ | ------------- | ------------------------------------------------------------------ |
| 홈     | `#home`       | 시작하기, 발송 상태, 최근 처리 내역                                |
| 계정   | `#accounts`   | Instagram 계정                                                     |
| 자동화 | `#automation` | 댓글 자동화, 플로                                                  |
| 인박스 | `#inbox`      | 인박스                                                             |
| 연락처 | `#contacts`   | 연락처                                                             |
| 설정   | `#settings`   | 작업 공간 설정, 운영 상태, 외부 전송, 인박스 라벨, 라벨 규칙, 멤버 |

## 시작하기

홈의 시작하기는 소유자와 관리자에게만 보이며, 세 단계를 모두 마치면 숨깁니다.
상담원은 계정을 연결하거나 설정을 바꿀 수 없으므로 보지 않습니다.

1. Instagram 계정 연결: 연결이 하나 이상 있으면 완료입니다. 계정 화면으로 이동합니다.
2. 첫 댓글 규칙 만들기: 규칙이 하나 이상 있으면 완료입니다. 1단계 전에는 잠겨 있고, 자동화 화면으로 이동합니다.
3. 발송 켜기: 발송 설정을 켠 계정이 하나 이상 있고 서비스 전체 발송이 켜져 있으면 완료입니다. 1단계 전에는 잠겨 있고, 계정 화면으로 이동합니다. 전체 발송이 중지되어 있으면 계정의 발송 설정과 관계없이 미완료로 두고 그 사실을 함께 안내합니다.

단계 상태는 계정·규칙·발송 설정을 다시 읽는 `loadWorkspace()`에서 매번 다시 계산하므로, 연결·규칙 저장·발송 설정 변경 뒤에 바로 반영됩니다.

## 주소와 이동

- 메뉴 이동은 주소의 `#` 값만 바꾸며, 서버에 요청하지 않습니다. 뒤로·앞으로 이동도 메뉴를 바꿉니다.
- `#` 값이 메뉴 이름이면 그 화면을, 어떤 화면 안의 요소 ID이면(예: 이전 주소 `#inbox-section`) 그 요소를 담은 화면을 보여 줍니다.
- 그 밖의 값(본문 바로가기 `#main`, 인증 링크의 `access_token=…`, 초대 링크의 `invite=…`)은 화면을 바꾸지 않습니다. 첫 로그인 화면은 주소가 메뉴를 가리키지 않으면 홈입니다.
- 화면 전환은 구역을 숨기고 보일 뿐 지우지 않으므로, 다른 메뉴로 갔다 와도 작성 중인 규칙·플로·답장 초안과 입력값이 남습니다.

## 접근성

- 메뉴는 링크 목록이며, 현재 화면의 링크에 `aria-current="page"`를 붙입니다.
- 메뉴를 눌러 화면을 바꾸면 페이지 맨 위로 이동하고 그 화면(`aria-label`이 메뉴 이름인 영역)에 초점을 옮깁니다. 첫 표시에서는 초점을 옮기지 않습니다.
- 잠긴 단계는 이동 링크 대신 먼저 마칠 단계를 글로 알려 줍니다.

## 수용 기준

1. 로그인하면 홈만 보이고, 소유자·관리자는 미완료 단계가 있을 때 시작하기를 봅니다.
2. 각 메뉴는 위 표의 구역만 보여 주며, 역할로 숨긴 구역은 메뉴를 바꿔도 숨겨진 채입니다.
3. 계정 연결, 첫 규칙 저장, 발송 설정 변경이 홈의 단계 상태에 바로 반영되고, 세 단계를 마치면 시작하기가 사라집니다.
4. 뒤로 가기, 이전 구역 주소, 본문 바로가기, 인증·초대 링크가 위 규칙대로 동작합니다.
5. 다른 메뉴로 갔다 와도 작성 중인 내용이 남습니다.
6. 390px 폭에서 메뉴가 가로로 넘치지 않습니다.

## 검증 경계

화면 검증은 [이전 화면 검증](../notes/2026-10-04-inbox-label-rules-ui-verification.md)과 같은 방식으로, 실제 `public/app` 파일과 실제 `appApi`를 일회용 로컬 PostgreSQL에 연결한 임시 서버에서 합성 데이터로 수행합니다.
운영 화면, 실제 Instagram 연결과 발송은 확인하지 않습니다.
