# Instagram 연결 상태 수동 확인

## 목적

계정 목록의 토큰 만료 시각만으로는 Meta 계정 접근과 웹훅 구독이 현재 가능한지 알 수 없습니다.
운영자가 각 연결에서 상태 확인을 실행하면 서버가 저장된 토큰으로 Meta를 조회하고 결과를 보여 줍니다.

## 동작

- 인증된 사용자가 소유한 연결만 확인할 수 있습니다.
- 토큰이 없거나 만료됐으면 Meta에 요청하지 않고 재연결 필요 상태를 반환합니다.
- 유효한 토큰으로 계정 ID를 조회한 뒤 해당 계정의 `comments`, `messages`, `messaging_postbacks` 구독 필드를 조회합니다.
- 계정 ID가 다르거나 Meta가 계정 접근·권한을 명시적으로 거부하면 재연결 필요 상태를 반환합니다.
- Meta 오류 코드 10, 190, 200–299는 권한·토큰 거부로 분류하며, 일시적인 오류나 형식을 알 수 없는 오류는 확인 불가로 둡니다.
- 필요한 구독 필드가 반환되면 필드 확인 상태를 보여 줍니다.
- 구독 필드가 부족하고 다음 페이지도 없으면 필드 누락 상태를 반환합니다.
- Meta 응답의 구독 ID가 알려진 앱 ID와 일치하지 않아, 이 조회만으로 현재 앱의 구독을 확정하지 않습니다.
- 시간 초과, 일시적인 오류, 응답 형식 변경, 다음 페이지에 남은 구독은 확인 불가로 반환합니다.
- 응답에는 토큰, Meta 원문, 다른 앱의 정보가 포함되지 않습니다.
- 조회 결과는 요청 시점의 진단이며 이후 권한이나 실제 이벤트 수신을 보증하지 않습니다.

## 이번 범위 밖

- 진단 결과를 DB에 저장하거나 자동 발송 판단에 사용하지 않습니다.
- 권한 목록·App Review·Advanced Access 승인 여부를 이 조회만으로 판정하지 않습니다.
- 자동 주기 검사와 발송 차단은 #16의 다음 단계로 남깁니다.

## 검증

1. 다른 작업 공간의 연결이나 잘못된 ID로는 Meta에 요청하지 않습니다.
1. 토큰 없음·만료·계정 불일치·구독 필드 누락·확인 불가·필드 확인을 구분합니다.
1. 공급자 오류 본문과 토큰은 API 응답에 나타나지 않습니다.
1. 계정 화면은 확인 시각과 결과를 표시하되 권한 승인이나 실제 수신을 보증하지 않습니다.
