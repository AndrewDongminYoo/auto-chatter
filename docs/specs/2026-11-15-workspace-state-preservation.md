# 작업 공간 갱신과 입력 상태 보존

## 문제와 범위

[#352](https://github.com/AndrewDongminYoo/auto-chatter/issues/352)는 규칙 저장이나 계정 설정 갱신으로 보고서 조건이 초기화되고, 네트워크 오류에서 로그인과 작업 공간이 함께 나타나는 문제를 다룹니다.
인증 확인, 작업 공간 데이터 갱신, 기능별 입력 초기화의 경계를 분리합니다.
바닐라 JavaScript와 기존 API를 유지하며 프레임워크 전환, 운영 배포, 실계정 연결과 메시지 발송은 포함하지 않습니다.

## 동작 계약

- 같은 사용자·작업 공간·권한의 갱신은 관련 없는 보고서 조건과 조회 결과, 규칙·연락처·플로·캠페인 입력을 보존합니다.
- 사용자·작업 공간·권한이 바뀌면 이전 화면과 진행 중 응답을 폐기합니다.
- 시간대나 조회 대상이 바뀌어 결과가 더 이상 유효하지 않으면 해당 기능이 결과를 초기화합니다.
- 인증 필요 상태에서만 로그인 화면을 표시합니다. 네트워크 실패는 재시도 경로를 제공하며 기존 작업 공간을 로그인 화면과 함께 표시하지 않습니다.
- 핵심 데이터를 모두 읽은 뒤 갱신을 반영합니다. 부가 기능 조회 실패는 해당 기능의 오류 안내로 남기며, 최신 재시도보다 늦게 도착한 응답은 반영하지 않습니다.
- 규칙 저장은 필요한 조작만 잠급니다. 관련 없는 보고서 요청의 busy 상태를 전체 버튼 복원으로 덮어쓰지 않습니다.

## 수용 기준과 검증 경계

합성 API와 실제 브라우저 컨트롤러를 이용해 보고서 기간 보존, 401, 네트워크 실패, 재시도 순서 역전과 세션 격리를 검증합니다.
타입 검사, ESLint, 전체 단위 테스트와 Trunk 게이트를 통과해야 합니다.
로컬 mock 미리보기에서 desktop·320px·390px, light/dark, 키보드·포커스와 빈 상태·오류 상태를 확인합니다.
실제 보조기술과 전체 접근성 수용은 #63의 범위로 남깁니다.

## 브라우저 재현

한 터미널에서 `python3 -m http.server 8768 --bind 127.0.0.1 --directory public`로 정적 파일을 제공합니다.
별도의 격리된 브라우저 세션에서 `http://127.0.0.1:8768/app/`을 연 뒤, `scripts/workspace-state-acceptance.mjs` 전체를 페이지의 비동기 JavaScript 평가로 실행합니다.
스크립트는 loopback 주소에서만 실행되며 모든 API 호출을 합성 응답으로 대체합니다.
검사가 끝나면 `workspaceFixture.offline`, `workspaceFixture.unauthorized`, `workspaceFixture.activityFailure`를 바꾸고 `start()`를 실행하여 오류 화면을 확인할 수 있습니다.
브라우저를 새로고침하면 합성 응답 설정이 사라집니다.
