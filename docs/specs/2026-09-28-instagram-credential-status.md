# Instagram 연결의 로컬 인증 상태 안내

## 문제

계정 화면은 수신 설정이 켜져 있으면 토큰이 만료됐어도 `수신 중`으로 표시합니다.
운영자는 설정 상태와 실제 발송 자격을 혼동할 수 있습니다.

## 범위

- 연결 목록 API는 저장된 토큰과 만료 시각으로 `credential_status`를 `missing`, `expired`, `valid` 중 하나로 반환합니다.
- 이 값은 요청 시점의 로컬 인증정보 상태만 나타냅니다.
- 화면은 API의 상태를 우선합니다. API가 이 값을 반환하지 않을 때만 브라우저 시계로 만료를 추정합니다.
- 화면은 토큰이 없거나 만료된 계정에 재연결 안내를 표시하고, 수신·발송 설정이 실제 동작을 보증하는 것처럼 표현하지 않습니다.
- 재연결 전에는 만료·미등록 계정의 발송 켜기와 수신 재개를 막습니다. 수신 중지는 기존 서버 정책에 따라 발송 설정도 함께 끕니다.
- 토큰 만료일이 남아 있어도 토큰 철회, Meta 권한과 웹훅 구독은 확인되지 않았다고 안내합니다.
- 기존 서버의 만료 토큰 발송·설정 차단 정책은 유지합니다.

## 비목표

- Meta 권한 철회, 웹훅 구독 유실 또는 실제 메시지 수신을 이 값만으로 판정하지 않습니다.
- 공급자 호출, 새 권한 요청, 운영 DB 변경, 실제 메시지 발송은 포함하지 않습니다.

## 수용 기준

1. 다른 작업 공간의 연결은 목록에 나타나지 않고, 토큰 없음·만료·유효 상태는 각각 정확하게 구분됩니다.
1. 만료된 계정은 `수신 중`으로 표시되지 않고 같은 Instagram 계정의 재연결 방법을 안내합니다.
1. 수신을 중지한 유효 계정에는 자동 갱신이 중지된다는 기존 안내가 유지됩니다.
1. 화면에서 권한과 웹훅 구독을 확인했다고 주장하지 않습니다.
