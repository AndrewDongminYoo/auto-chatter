# 공개 URL 네트워크 재측정 범위

## 문제와 목표

[#199](https://github.com/AndrewDongminYoo/auto-chatter/issues/199)는 2026-10-12의 해외 데이터센터 처리와 느린 응답을 기록했습니다.
정적 파일 개선은 #200에 반영됐으므로, 이번 작업은 현재 응답과 기존 증거를 비교하는 문서화입니다.
일회성 측정으로 이슈를 해결 처리하지 않습니다.

## 수용 기준

- 인증 없이 서비스의 공개 페이지·앱 HTML·로고와 비교 호스트를 각각 세 번 읽습니다.
- UTC 시각, HTTP 상태, 데이터센터 식별자, 연결·TLS 완료 시간, 첫 바이트 시간, 총시간, 본문 크기, 종료 코드를 기록합니다.
- 별도로 ETag 조건부 요청과 HTTP/2 연결 재사용을 확인합니다.
- ICMP 결과에는 표본 수를 표시하며 HTTP 손실률로 해석하지 않습니다.
- 현재 ISP·VPN·다른 통신사·IPv6·브라우저 표시 성능의 미확인 상태를 명시합니다.
- 공개 문서에는 방문자 IP, 쿠키, 인증 정보, trace 원문을 넣지 않습니다.

## 제외 범위

운영 설정·DNS·요금제·코드·DB·배포를 변경하지 않습니다.
지원 문의 발송과 #199 종료도 포함하지 않습니다.
측정과 공식 문서로 확인할 수 없는 원인을 추정하여 단정하지 않습니다.
