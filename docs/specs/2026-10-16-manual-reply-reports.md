# 수동 답장 현황 리포트

## 목적과 범위

[#50](https://github.com/AndrewDongminYoo/auto-chatter/issues/50)의 첫 단계로, 소유자와 관리자가 특정 기간에 접수한 수동 답장의 현재 상태를 확인합니다.
생성 시각으로 대상을 고른 뒤 조회 시점의 상태를 집계하므로, 그 기간에 일어난 상태 변경이나 발송 횟수를 뜻하지 않습니다.
자동화·플로·캠페인·상담 전환·비용 분석은 포함하지 않으며 #50을 완료 처리하지 않습니다.

## 조회 계약

`GET /api/reports/manual-replies`는 `admin` 이상만 사용할 수 있습니다.
`from`과 `before`는 작업 공간 시간대의 `YYYY-MM-DD` 날짜이며, 시작일은 포함하고 종료일은 제외합니다.
기간은 1~366일이고, `expected_time_zone`은 화면에서 확인한 현재 작업 공간 시간대와 정확히 같아야 합니다.
선택 항목인 `connection_id`는 같은 작업 공간의 연결 UUID입니다.
미지정하면 모든 연결을 포함하며 비활성 연결도 포함합니다.
알 수 없는 매개변수, 중복 키, 잘못된 날짜, 빈 기간과 과도한 기간은 400으로 거부합니다.
다른 작업 공간 또는 없는 연결은 404, 바뀐 시간대는 409로 거부합니다.

PostgreSQL이 각 날짜의 자정을 현재 작업 공간 시간대로 변환합니다.
DST 전환일은 23시간 또는 25시간이 될 수 있으며, 실제 UTC 경계도 응답에 담습니다.
존재하지 않거나 겹치는 자정은 PostgreSQL의 시간대 변환 규칙을 따릅니다.
멤버십·시간대·연결 범위·집계는 한 SQL 문장의 스냅샷에서 확인합니다.
조회 중 이후에 확정된 권한 변경은 이미 시작한 응답을 회수하지 못합니다.
`(workspace_id,created_at,connection_id)` 인덱스는 계정 필터 유무와 관계없이 작업 공간과 생성 기간으로 읽기 범위를 좁힙니다.

## 집계 의미

응답은 조회 시각, 시간대, 날짜 및 UTC 경계, 선택 연결 ID, 다음 십진수 문자열 건수를 담습니다.

| 항목               | 의미                                                                 |
| ------------------ | -------------------------------------------------------------------- |
| total              | 선택 기간에 생성된 저장 요청 수                                      |
| pending            | 대기 중이며 미래 예약과 보류된 요청도 포함                           |
| sending            | 발송 처리 중                                                         |
| sent               | Meta가 발송 요청을 접수한 상태                                       |
| failed             | 실패 또는 발송 전 정책 검사에서 거부된 상태                          |
| unknown_unresolved | 발송 결과를 확인하지 못했고 운영자가 정리하지 않은 상태              |
| unknown_resolved   | 발송 결과를 확인하지 못했지만 운영자가 재발송하지 않기로 정리한 상태 |
| cancelled          | 취소된 예약 요청                                                     |

상태별 일곱 건수의 합은 total과 같습니다.
반복 접수와 여러 감사 이벤트는 같은 요청 행을 중복 집계하지 않습니다.
명시적 재시도는 별도 요청 행으로 계산하며, 고유 고객 수나 논리적 메시지 수로 표현하지 않습니다.
예약 수정은 최초 생성 기간을 바꾸지 않습니다.
삭제된 데이터는 포함하지 않으므로 보존된 원장의 현재 집계이며 영구적인 과거 통계가 아닙니다.
`sent`는 전달·읽음·전환·매출을 증명하지 않습니다.
정리한 unknown도 sent로 바꾸거나 합산하지 않습니다.
메시지 본문, 수신자·발신자 식별자, 인증정보와 실패 원문은 반환하지 않습니다.

## 화면과 CSV

홈에서 관리자에게만 수동 답장 현황 영역을 표시합니다.
날짜와 선택 계정을 지정해 조회하며, 기본 날짜는 작업 공간 시간대 기준 최근 7일입니다.
브라우저가 서버의 시간대를 표시하지 못하면 기본 날짜를 채우지 않고 직접 입력하도록 안내하며, 조회 시각은 UTC로 표시합니다.
기간 경계는 계속 서버의 작업 공간 시간대로 계산합니다.
화면은 조회한 기간·시간대·시각과 상태별 건수를 함께 표시합니다.
입력 변경, 새 조회 시작, 역할 또는 작업 공간 재초기화, 로그아웃 시 기존 결과와 CSV 내보내기를 무효화합니다.
지연된 응답은 이후 입력이나 세션의 화면을 덮어쓰지 못합니다.
CSV는 화면에 표시한 응답 하나에서 생성하며 별도 재조회로 수치가 달라지지 않습니다.
고정된 지표명, 날짜, 검증된 시간대와 연결 UUID만 내보내며 계정 표시 이름과 고객 데이터는 내보내지 않습니다.
CSV는 현재 화면의 조회 결과이며 이후 상태 변경을 자동 반영하지 않습니다.

## 검증과 운영 경계

격리 DB 테스트로 권한, 타 작업 공간 격리, 일곱 상태, 중복 이벤트, 명시적 재시도, 시간 경계, DST, 잘못된 입력과 빈 결과를 검사합니다.
브라우저에서 표시·CSV·입력 무효화·지연 응답·세션 초기화와 좁은 화면을 확인합니다.
새 테이블, 의존성, 실제 발송 또는 운영 변경은 없습니다.
기존 DB는 코드 배포 전에 전체 `deploy/migrate-multi-user.sql` 실행기로 기간 조회 인덱스 migration 050을 적용해야 합니다.
실행기는 한 트랜잭션 안에서 일반 인덱스를 생성하므로 적용 중 해당 테이블 쓰기가 대기할 수 있습니다.
운영 적용과 그 작업 시간 승인은 별도로 진행합니다.

## 선례

Oracle이 반환한 `wiki/concepts/source-verified-output.md`와 원문 `raw/sources/.claude/rules/source-verified-output.md`는 근거가 증명하는 의미만 표시하도록 요구합니다.
이 원칙에 따라 원장의 현재 상태만 집계하고 Meta 접수를 전달·읽음으로 확대하지 않습니다.
최초 검색은 일부 결과만 반환했으며 위키 현재 버전과의 일치는 확인하지 못했습니다.
