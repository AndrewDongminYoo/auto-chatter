# 발송 설정과 차단 사유 안내

## 문제와 범위

[#353](https://github.com/AndrewDongminYoo/auto-chatter/issues/353)의 기존 발송 상태 안내를 홈·계정·규칙 편집·인박스에서 일관되게 설명합니다.
전체 발송 설정은 서비스 운영자의 조치, 계정 설정과 재연결은 계정 관리자의 조치, 규칙 활성화는 저장이 필요한 조치로 구분합니다.
계정 정보는 마지막 작업 공간 조회 결과이며, 토큰 만료 전이라는 사실이 연결 권한 확인이나 발송 자격을 증명하지 않습니다.

## 동작과 비목표

공통 설명은 전체 중지, 계정 발송·수신 중지, 토큰 또는 연결 확인 필요, 규칙 중지를 함께 표시합니다.
전체 설정 재조회 실패는 확인 필요로 표시하며, 오래된 응답과 세션 교체 후의 응답은 적용하지 않습니다.
재조회는 기존 입력과 조회 조건을 유지하며 계정 목록이나 대화를 다시 만들지 않습니다.
인박스에서는 선택한 대화의 계정 설정을 표시하되 직접 답장 자격과 24시간 창은 기존 서버 결과를 따릅니다.
설정 활성화를 실제 발송·전달 보장으로 표현하지 않습니다.
서버 정책, outbox 상태, 운영 배포, 실계정 연결과 실제 메시지 발송은 범위 밖입니다.

## 수용 기준

- 전역·계정·규칙 설정 조합과 조회 실패에서 이유와 다음 조치가 모순되지 않습니다.
- 재조회 성공·실패·세션 교체 시 초안과 필터를 보존하며 폐기된 응답을 차단합니다.
- 상태 안내는 색상에만 의존하지 않고 접근 가능한 상태 영역에서 전달합니다.
- 합성 API 브라우저 회귀와 desktop·320/390px 및 light/dark 렌더링을 확인합니다.
- 타입 검사, lint, 단위 테스트와 전체 Trunk 게이트를 실행하고 제한을 기록합니다.
