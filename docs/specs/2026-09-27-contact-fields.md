# 연락처 사용자 정의 필드

## 목적

연락처별 관심 항목·점수·동의 상태 같은 운영 정보를 직접 저장하고 검색 조건으로 사용합니다.
2026-09-27 확인한 [ManyChat 사용자 정의 필드 문서](https://help.manychat.com/hc/en-us/articles/14281167138588-Custom-User-Fields-and-Bot-Fields)는 연락처별 값과 검색·자동화 활용을 설명합니다.
이 회차는 필드 관리와 검색을 구현하며 자동 수집·메시지 변수·Bot Fields는 전체 제품의 후속 기능으로 유지합니다.

## 계약

- 필드 정의는 작업 공간에 속하며 이름과 변경할 수 없는 타입을 갖습니다.
- 타입은 text, number, boolean, date입니다. date는 유효한 YYYY-MM-DD 날짜입니다.
- 이름은 NFC·앞뒤 공백 제거 후 1–60자이며 제어 문자를 거부합니다. 보관한 이름도 재사용하지 않습니다.
- 작업 공간당 활성 필드는 50개이며 동시 생성에서도 제한을 지킵니다. 이는 서비스 자체 제한입니다.
- 값은 작업 공간·Instagram 연결·sender·필드로 구분하며 다른 계정의 같은 sender와 합치지 않습니다.
- 값은 타입에 맞게 저장하고 문자열을 숫자·boolean으로 자동 변환하지 않습니다. text는 최대 1000자이며 제어 문자를 거부하되 줄바꿈과 탭은 허용합니다.
- number는 유한한 JavaScript 숫자입니다. false, 0, 빈 text는 저장된 값이며 null은 값 제거입니다.
- 본문은 value 키 하나만 허용하며 등록되지 않은 연락처·외부 작업 공간의 필드·보관된 필드는 404입니다.
- 생성·보관·값 변경은 서버 인증과 동일 출처 검사를 사용합니다. 서버의 기존 SELECT/INSERT/UPDATE 접근과 RLS를 유지합니다.
- 연락처 조회에 필드 값이 포함되며 보관된 필드 값은 표시하지 않습니다. 필드를 보관해도 값은 삭제하지 않습니다.
- 필드 검색은 한 필드의 eq, is_set, is_unset 조건과 숫자·날짜의 gt, gte, lt, lte 조건을 지원합니다. 계정·태그 조건과 AND로 결합하며 현재 값을 조회합니다.
- 값 비교는 타입에 맞는 JSON 스칼라 값을 사용합니다. 숫자 순서로 비교하며 날짜는 검증된 YYYY-MM-DD의 일자 순서로 비교합니다. 텍스트·boolean의 순서 비교와 문자열을 숫자로 바꾸는 요청은 거부합니다. 미입력은 빈 문자열·false·0과 다르며 순서 비교에 포함하지 않습니다.
- 저장된 필터에도 같은 조건을 저장합니다. 수동 조건과 segment_id는 혼합할 수 없습니다.
- 활성 저장 필터가 참조하는 필드의 보관은 409 field_in_use로 거부합니다. 보관과 참조 생성의 경쟁에서도 이 계약을 유지합니다.
- 화면은 필드 생성·보관, 연락처 값 편집·제거, 타입에 맞는 조건 입력을 제공합니다. 실패 시 초안을 유지하고 로그아웃 뒤 늦은 응답을 차단합니다.

## 경계와 비목표

이 값은 발송 동의나 정책상 발송 가능 상태를 자동으로 부여하지 않습니다.
필드 정의 이름·타입 변경, 보관 해제, 영구 삭제와 조건 조합 언어는 후속 범위입니다.
숫자·날짜 비교는 [#26](https://github.com/AndrewDongminYoo/auto-chatter/issues/26)의 일부이며 AND/OR·동의·활동 조건, 대상 미리보기와 캠페인 대상 고정은 남아 있습니다.
마이그레이션 036을 전체 마이그레이션 실행기로 적용해야 비교 조건을 저장할 수 있습니다.
운영 DB 마이그레이션·배포·실계정 변경·발송은 수행하지 않습니다.
Oracle 조회는 `[no precedent found]`이며 Wiki freshness는 확인되지 않았습니다.

## 수용 기준

실제 로컬 PostgreSQL로 타입 검증·값 제거·계정과 작업 공간 격리·최신 값 검색·동시 제한·보관 경쟁·마이그레이션 재실행을 확인합니다.
제한된 서버 역할의 workerd로 인증된 생성·값 변경·검색·보관을 실행하고 RLS와 DELETE 권한 부재를 검사합니다.
실제 로컬 화면에서 저장 실패·초안 보존·필터 전환·늦은 응답과 모바일 가로 넘침을 검사하며 화면 승인을 받습니다.
