# 관리자 연락처 CSV 내보내기

## 범위와 권한

[#25](https://github.com/AndrewDongminYoo/auto-chatter/issues/25)의 CSV **내보내기만** 구현합니다.
기존 [작업 공간 JSON 내보내기](2026-09-30-workspace-export.md)와 같은 소유자·관리자 권한입니다.
상담원은 직접 URL을 호출해도 거절합니다. 기존 JSON 내보내기는 그대로 유지합니다.
연락처 상세는 [PR #139](https://github.com/AndrewDongminYoo/auto-chatter/pull/139)로 이미 병합됐으며 이 CSV 변경에서 수정하지 않습니다.
CSV 가져오기·중복 검증·미리보기·식별자 병합/분리·동의 원장 변경은 포함하지 않습니다.
#17·#27의 외부 검증과 #25의 전체 완료 조건은 열린 상태로 남습니다.

## 파일 범위와 형식 v1

작업 공간의 저장된 댓글 연락처 전체를 내보냅니다. 연결 해제한 계정도 포함합니다.
작업 공간·연결·댓글 작성자별 한 행이며 반복 댓글은 합칩니다. 다른 연결의 같은 작성자 ID는 별도 행입니다.
현재 화면의 50명 페이지·필터·저장 전 태그/필드 수정은 내보내기 범위에 영향을 주지 않습니다.
댓글·DM 원문 테이블, DM 연결 근거, 동의 근거, 자격 증명, 멤버·상담 메모·개인 리마인더는 제외합니다.
**활성 사용자 정의 필드에는 수집한 답장 등 개인정보가 들어 있을 수 있습니다.**

UTF-8 BOM을 한 번 붙이고, 모든 셀을 큰따옴표로 감싸 내부 큰따옴표는 두 번 쓰며, 쉼표와 CRLF로 구분합니다.
연락처가 없으면 같은 헤더만 반환합니다. 헤더는 아래 14개로 고정하며 필드 이름으로 동적 열을 만들지 않습니다.

| 열                          | 값                                                                         |
| --------------------------- | -------------------------------------------------------------------------- |
| `format_version`            | `1`                                                                        |
| `exported_at`               | 모든 행에 같은 트랜잭션 시각, UTC·마이크로초                               |
| `workspace_id`              | 호출자의 작업 공간 UUID                                                    |
| `channel`                   | `instagram`                                                                |
| `identity_kind`             | `comment_sender`                                                           |
| `connection_id`             | 연결 UUID                                                                  |
| `sender_id`                 | 댓글 작성자 문자열에 표시용 작은따옴표 하나를 덧붙인 값                    |
| `connection_username`       | 연결 계정 이름. 연락처의 프로필 이름이 아님                                |
| `first_comment_recorded_at` | 첫 댓글의 서비스 저장 시각, UTC·마이크로초                                 |
| `last_comment_recorded_at`  | 최근 댓글의 서비스 저장 시각, UTC·마이크로초                               |
| `comment_count`             | PostgreSQL이 반환한 십진수 문자열                                          |
| `automation_paused`         | 직접 중지 또는 상담 전환 중지이면 `true`, 나머지 `false`. 발송 자격이 아님 |
| `tags_json`                 | 문자열 배열 JSON, 문자순 정렬                                              |
| `fields_json`               | 활성 필드 UUID를 키로 `{name,type,value}`를 담은 JSON 객체, UUID 순서      |

필드의 `0`, `false`, 빈 텍스트, 날짜와 숫자는 자료형을 유지하고 미설정/NULL·보관 필드는 뺍니다.
필드 JSON은 PostgreSQL에서 만든 텍스트 그대로 사용하여 JavaScript 숫자 정밀도로 반올림하지 않습니다.
ID와 댓글 수도 JavaScript Number로 변환하지 않습니다.
행은 연결 UUID, 작성자 텍스트의 `C` 정렬 순서입니다.

## 표시용 작은따옴표와 수식 문자열

`sender_id`는 항상 작은따옴표 하나를 먼저 붙여 숫자 자동 변환에 따른 앞자리 0과 큰 숫자의 손실을 피하도록 표시합니다.
연결 계정 이름은 빈 문자열, 원래 작은따옴표로 시작하는 문자열, 선행 공백·제어·서식 문자 뒤의 `=`, `+`, `-`, `@`와 전각 형태, 선행 탭/CR/LF가 있는 경우에만 같은 표시를 붙입니다.
일반 계정 이름은 그대로 둡니다. 원래 이름이 `'shop`이면 파일 셀 값은 `''shop`입니다.

원래 스칼라 문자열을 복원하려면 맨 앞의 작은따옴표가 있을 때 **하나만** 제거합니다.
계정 이름의 NULL은 표시 없는 빈 셀이고, 원래 빈 문자열은 작은따옴표 하나인 셀이므로 구분됩니다.
태그와 필드 셀은 `[` 또는 `{`로 시작하는 JSON이며, 중첩 문자열은 JSON 이스케이프와 CSV 인용을 함께 적용합니다.
이 파일은 스프레드시트 표시용 형식이며 그대로 가져오기용 값이라는 계약은 없습니다.
스프레드시트 앱마다 작은따옴표 해석이 다를 수 있고, 편집·변환·다시 저장한 파일에서는 보호 표시가 사라질 수 있습니다.
생성한 파일의 인코딩 검증을 모든 앱과 저장/재열기의 안전성 보장으로 확대하지 않습니다.

## API·스냅샷·한도

`GET /api/contacts/export.csv`는 query를 받지 않습니다. 미지원/중복 매개변수는 `400 invalid_contact_export_request`입니다.
멤버십과 역할을 `REPEATABLE READ READ ONLY` 트랜잭션 안에서 조회하며, 멤버가 없거나 제거됐으면 `403 workspace_required`, 상담원이면 `403 role_forbidden`입니다.
연락처·태그·중지·필드를 같은 스냅샷에서 내부적으로 25행씩 읽습니다. 클라이언트 커서는 없습니다.
삭제/권한 변경이 스냅샷 전에 커밋되면 반영되지만, 이미 시작한 스냅샷 내보내기는 그 이후 변경 전 데이터를 포함할 수 있습니다.
긴 쓰기 잠금으로 삭제를 막거나 이미 다운로드한 파일을 회수하지 않습니다.

서비스 한도는 연락처 5,000개, 최종 CSV 5 MiB(UTF-8 BOM·인용·CRLF 포함), 내보내기 작업 10초입니다.
바이트는 행을 보관하기 전에 실제 UTF-8 크기로 계산하며 한도를 넘으면 전체 요청을 거절합니다.
10초 예산은 연결 획득·조회·직렬화 전체에 하나만 적용하고, 각 DB 쿼리의 남은 시간을 제한합니다.
인증 미들웨어와 오류 후 연결 정리까지 포함한 HTTP 응답의 절대 10초 완료를 보장한다는 뜻은 아닙니다.
늦게 획득한 연결은 즉시 닫고, 시간 초과 뒤 아직 실행 중일 수 있는 쿼리의 클라이언트도 닫아 풀로 반환하지 않습니다. 연결 종료는 읽기 트랜잭션을 롤백합니다.
다른 오류는 명시적으로 롤백하고, 롤백이 실패하면 연결을 닫습니다.

행/바이트 초과는 `422 contact_export_too_large`, 시간 초과는 `503 contact_export_timeout`입니다.
성공적으로 모두 직렬화하고 커밋한 뒤에만 파일 응답을 만듭니다. 부분 CSV나 조용한 잘라내기는 없습니다.
본문은 `text/csv; charset=utf-8`, `Cache-Control: no-store`, `X-Content-Type-Options: nosniff`이며 파일명은 서버가 만든 `auto-chatter-contacts-v1-YYYY-MM-DD.csv`입니다.
조회 중 쓰기·큐 알림·공급자 호출·셀 내용 로그를 남기지 않습니다.

## 화면

소유자·관리자에게만 연락처 새로고침 옆의 “전체 연락처 CSV” 버튼과 전체 범위·저장 전 수정 제외·개인정보 안내를 보여줍니다.
표시 형식·복원·다시 저장의 주의점은 기본적으로 접힌 “CSV 값 읽는 방법”에서 키보드로 펼쳐 확인합니다.
중복 요청을 막고 진행·실패·완료는 한국어 aria-live 영역에 표시합니다.
필터 변경은 진행 중인 전체 내보내기를 취소하거나 좁히지 않고, 태그·필드 편집 DOM도 바꾸지 않습니다.
로그아웃·작업 공간 재조회/전환·화면에서 실행한 연결 데이터 삭제는 이전 요청의 다운로드를 무효화합니다.
텍스트 응답 디코딩에서 BOM이 제거될 수 있으므로 실제 Blob에는 정확히 하나를 복원하고, 객체 URL은 다운로드 후 해제합니다.
