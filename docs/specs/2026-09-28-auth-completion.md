# 인증 경로 마무리

## 목표

이슈 #15에서 남은 이메일 확인, 복구 링크, 로그아웃, 공개 인증 요청의 남용 제한을 완성합니다.

## 동작

- 가입과 인증 메일 재전송은 주소 형식을 확인합니다.
  공급자가 계정 상태나 발송 간격 때문에 요청을 거절해도 동일한 안내를 반환합니다.
- 만료된 인증·복구 링크를 열면 링크가 유효하지 않다는 안내와 재요청 경로를 보여줍니다.
  URL 조각에 담긴 토큰과 오류 정보는 화면을 표시하기 전에 주소에서 제거합니다.
- 로그인, 가입, 복구, 인증 메일 재전송 요청은 공급자 호출 전에 접속 IP·경로별 분당 30회 제한과 정규화한 이메일별 분당 5회 제한을 통과해야 합니다.
  제한 키마다 Durable Object(`AuthLimiter`) 하나가 고정 창의 요청 수를 세며, 거절된 요청도 셉니다. 창이 끝나면 알람이 저장한 창을 지웁니다.
  가입·복구·인증 메일 재전송은 하나의 이메일 제한을 공유하며, 로그인은 별도의 이메일 제한을 사용합니다.
  이메일은 SHA-256 해시만 제한 키에 사용합니다.
- 메일을 보내는 세 요청(가입·복구·인증 메일 재전송)은 그 위에 접속 IP별 시간당 10회 제한과 프로젝트 전체 시간당 20회 제한을 통과해야 합니다([#165](https://github.com/AndrewDongminYoo/auto-chatter/issues/165)).
  Supabase의 사용자 지정 SMTP 메일 한도(시간당 30통)는 프로젝트 전체에 하나뿐이고, 이 세 요청은 계정 존재 여부를 숨기려고 공급자의 401과 429를 성공으로 응답합니다. 그래서 한 클라이언트가 주소를 바꿔 가며 한도를 소진하면 실제 사용자는 성공 안내를 보지만 메일을 받지 못합니다.
  IP별 제한을 먼저 확인하므로, 자기 몫을 넘긴 클라이언트는 프로젝트 전체 몫을 쓰지 않습니다. 프로젝트 전체 제한은 Supabase 한도보다 낮게 두어, 한도에 걸리면 메일이 조용히 사라지는 대신 `429 auth_rate_limited`로 안내합니다. 이 제한은 계정 유무와 관계없이 같으므로 계정 존재 여부를 드러내지 않습니다.
  Supabase 메일 한도를 바꾸면 프로젝트 전체 제한도 함께 조정합니다.
- 로그아웃 요청은 Supabase 세션 종료를 확인한 뒤 브라우저 쿠키를 지웁니다.
  종료 확인에 실패하면 브라우저 쿠키를 지우되 성공으로 표시하지 않습니다.

## 한계와 운영 조건

처음에는 Cloudflare rate limit 바인딩을 썼지만, 이 바인딩은 Worker가 실행된 기계에 카운터를 캐시하므로 요청마다 새 연결을 열면 여러 기계로 흩어져 한도에 닿지 않았습니다(운영에서 확인, [#148](https://github.com/AndrewDongminYoo/auto-chatter/issues/148)). 그래서 키마다 요청이 한곳으로 모이는 Durable Object로 바꿨습니다.
Durable Object 호출이 실패하면 요청을 `503 auth_unavailable`로 거절합니다.
공유 네트워크의 사용자는 같은 IP 제한에 걸릴 수 있습니다.
Supabase Auth에도 별도의 프로젝트·IP·사용자별 제한이 있으므로 이메일이 실제로 도착했는지는 응답 코드만으로 보장하지 않습니다.
현재 공급자 호출은 공개 키를 사용하므로 최종 사용자 IP를 `Sb-Forwarded-For`로 전달하지 않습니다.
이 구성을 바꾸려면 비밀 API 키와 Supabase 설정 변경을 따로 검토해야 합니다.

## 수용 기준

1. 가입·재전송·복구 응답은 계정 존재 여부와 공급자 오류 본문을 드러내지 않습니다.
2. 제한 초과 요청은 HTTP 429를 반환하고 공급자를 호출하지 않습니다.
3. 만료 링크 안내와 재전송 버튼에 키보드로 접근할 수 있으며, 오류를 화면 읽기 도구에 알립니다.
4. 메일 확인 링크, 비밀번호 변경, 만료 링크, 로그아웃 후 이전 세션 거부를 실제 브라우저에서 확인합니다.

## 검증 경계

단위·Worker 테스트는 응답 분류, 제한 적용, 쿠키 및 공급자 호출 계약을 검사합니다.
실제 메일 배달과 Supabase의 세션 폐기는 배포 뒤 운영 브라우저에서 별도로 확인합니다.
