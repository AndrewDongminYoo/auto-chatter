# 대시보드 API 값 표시 보호

## 문제와 범위

#350의 API 값 직접 삽입으로 생기는 undefined, null, NaN, Invalid Date 표시를 막는다.
공통 표시 함수와 대시보드의 숫자·문자열·날짜 출력 지점을 보완한다.
정상 숫자의 기존 천 단위 구분 여부를 보존하며 문자열 ID를 숫자로 변환하지 않는다.
API 계약, 발송 판단, 저장 값과 서버 검증은 바꾸지 않는다.

## 완료 조건

누락·잘못된 표시 값은 `–`로 표시하고 정상 값과 0은 보존한다.
큰 정수인 문자열 건수는 정밀도를 잃지 않는다.
단위 테스트, 직접 삽입 재발 검사, 누락 필드 mock으로 각 메뉴를 연 미리보기로 확인한다.
렌더링 결과는 병합 전 운영자 승인을 받는다.
