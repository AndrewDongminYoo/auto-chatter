# 홈의 다음 행동과 보고서 진입

## 범위

[#354](https://github.com/AndrewDongminYoo/auto-chatter/issues/354)는 #353의 발송 안내를 유지하며 홈의 다음 행동과 최근 처리 내역을 우선합니다.
처음 사용하는 관리자는 계정 연결·첫 규칙·발송 설정 순서를 확인하고, 운영 중인 사용자는 계정·자동화·인박스의 진입점을 사용할 수 있습니다.
네 상세 보고서는 별도 보고서 화면으로 옮기되 기존 섹션 링크, 관리자 권한, 조회 조건·결과·CSV 계약을 보존합니다.
현재 API에 없는 성과 수치나 집계는 만들지 않습니다.

## 로딩과 보존

홈은 핵심 사용자·작업 공간·계정·규칙 정보와 최근 처리 내역만 요청합니다.
자동화·연락처·인박스·캠페인·설정·보고서에 필요한 부가 데이터는 해당 화면에 들어갈 때 읽습니다.
동일한 작업 공간 조회 뒤 화면 재진입과 동시 진입은 같은 초기화를 공유하며, 명시적 새로고침과 새 작업 공간 조회는 필요한 데이터를 다시 읽을 수 있습니다.
보고서의 맥락 변경·세션 교체는 기존 무효화 계약을 유지하며 단순 메뉴 이동으로 초안·조회 조건·결과를 초기화하지 않습니다.

## 수용 기준과 비목표

무계정·규칙 작성 전·운영 중 fixture에서 다음 행동과 공통 발송 상태를 확인합니다.
홈에서 네 보고서 입력이 기본으로 노출되지 않고, 보고서 이동·조회·CSV 및 조건 보존이 동작해야 합니다.
합성 API 요청 내역으로 홈 초기 요청과 화면 재진입의 중복 여부를 확인하고 운영 지연 수치로 확대하지 않습니다.
타입·lint·단위·전체 Trunk와 desktop·320/390px, light/dark 및 키보드·오류 상태를 검증합니다.
서버 API·발송 정책 변경, 운영 배포, 실계정 연결과 실제 발송은 포함하지 않습니다.
