# Instagram 연락처와 태그

## 목적

댓글 참여자를 계정별로 찾아보고 수동 태그로 분류합니다.
이 기능은 공유 인박스와 세그먼트 자동화의 첫 단계이며 DM 수신 동의나 구독 사용량을 뜻하지 않습니다.

명시적인 `GET /api/contacts?preview=true`는 동일한 필터·작업 공간 범위의 전체 연락처 수를 `total` 10진수 문자열로 함께 반환합니다.
같은 작업 공간·선택 계정의 평가 수 `evaluated`와 태그만·필드만·둘 다 불일치한 수 `excluded.tag`·`field`·`both`도 10진수 문자열로 반환합니다.
제외 사유는 중복되지 않으며 OR는 태그·필드 조건이 모두 불일치한 경우만 제외합니다.
[마지막 댓글 저장 기간](2026-10-16-segment-comment-activity.md)을 지정하면 기간 밖 연락처를 `excluded.activity`로 먼저 제외하고 기간 안에서 태그·필드 사유를 나눕니다.
[최근 댓글 활동](2026-10-16-segment-relative-activity.md)은 고정 기간 대신 1~366일을 지정하고 매 조회 시각 직전 N×24시간을 판정합니다.
실제 UTC 경계를 반환하며 다음 페이지도 다시 계산합니다.
[목적별 동의 기록](2026-10-16-segment-consent-state.md)을 지정하면 기간 판정 다음에 정확한 댓글 식별자의 현재 기록을 비교하여 `excluded.consent`로 제외하고, 나머지를 태그·필드 사유로 나눕니다.
DM 동의나 발송 가능 여부를 판정하지 않습니다.
첫 페이지 샘플과 모든 수는 같은 SQL 문장에서 읽고, 일치 대상이 0명이어도 요약을 반환합니다.
이 모드에서는 `after`를 허용하지 않습니다.
일반 목록의 페이지 처리와 응답 형태는 유지합니다.
상세 계약은 [초안 대상 미리보기](2026-10-16-segment-draft-preview.md)를 따릅니다.

## 계약

- 연결 계정과 댓글의 sender ID를 연락처 식별자로 사용합니다.
- 같은 계정의 반복 댓글은 연락처 한 건으로 표시하고 다른 계정의 동일 ID는 합치지 않습니다.
- 사용자 서버 인증 뒤 작업 공간으로 목록·필터·수정을 제한합니다.
- 첫 댓글·최근 댓글 시각, 댓글 수, 계정 이름과 태그만 반환하고 댓글 본문·토큰은 반환하지 않습니다.
- 최대 20개 태그를 NFC·앞뒤 공백 제거·소문자로 정규화하며 태그 하나는 최대 40자입니다.
- 태그 교체는 단일 upsert이며 빈 배열로 모두 제거합니다.
- 존재하는 댓글 참여자만 수정할 수 있고 외부 작업 공간과 존재하지 않는 연락처는 404입니다.
- 계정·태그 필터와 50건 단위의 식별자 기반 페이지 이동을 제공합니다.
- 선택적인 UTC 시작·종료로 마지막 댓글 저장 시각을 `[from,before)` 범위로 제한합니다.
  이전 댓글만 기간 안에 있는 연락처는 포함하지 않으며 댓글 수·첫 댓글 시각은 전체 저장 이력을 유지합니다.
- 필터 변경·로그아웃 뒤 도착한 오래된 응답은 화면에 적용하지 않습니다.

## 비목표와 한계

DM 참여자 병합, 이름·프로필 조회, CSV, 일괄 작업, 사용자 정의 필드, 저장된 세그먼트, 자동 태그와 발송은 후속 범위입니다.
Instagram의 댓글 ID와 DM ID가 같다고 추정하지 않습니다.
목록은 저장된 댓글 기준이며 연결 해제 후에도 승인된 수동 삭제 정책에 따라 보관합니다.
운영 DB 변경·배포·실발송은 이 PR에서 수행하지 않습니다.

## 수용 기준

실제 로컬 DB에서 중복 댓글·다른 계정·다른 작업 공간·태그 저장과 제거·필터·두 번째 페이지·마이그레이션 재실행을 확인합니다.
브라우저에서 빈 목록·태그 편집·필터·모바일 폭·실패 뒤 입력 보존·로그아웃 후 늦은 응답을 확인합니다.
Oracle의 프로젝트 전용 관련 선례는 `[no precedent found]`입니다.

후속 [CSV 내보내기](2026-10-04-contact-csv-export.md)와 [태그 사전 검사](2026-10-17-contact-csv-preview.md), [태그 변경 적용](2026-10-17-contact-csv-import.md)은 별도 범위로 구현했습니다.
사전 검사는 기존 댓글 연락처의 태그 변경 예상 결과를 보여주고, 적용은 오류·중복·조회 불가가 없는 파일의 변경 예상 행만 전부 아니면 전무로 교체합니다.
